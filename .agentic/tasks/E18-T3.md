## Goal

The runner hooks (ADR 0053). It covers:

- `run.py` loads `jobs.py` by path, and refreshes the index after each CLI write and each `Daemon._save`;
- daemon heartbeats, with migration 3 adding `daemons`;
- lease renewal for jobs with a command running;
- `jobs.py daemons`, and stale runner jobs;
- a failure is only a warning, and a missing `jobs.py` changes nothing.

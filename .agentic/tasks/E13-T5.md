## Goal

The live run on #82 found that Claude Code's `--allowedTools` takes any number of values, so with the default agent command it read the prompt as a tool name, and every session exited 1 with no prompt. The default now puts `--` before `{prompt}`, so the prompt is always read as the prompt.

## Acceptance criteria

- E13 AC-07 (amended 24 Nov 2026): the default `agent_command`, in the kit's config, `pipeline.py`'s defaults and the installer's schema, has `--` immediately before `{prompt}`, and `{prompt}` is its last item.
- A session's argv keeps the prompt as one argument after `--`.

## Notes

- Relock of E13-T1's tests (`tests/test_pipeline_config.py`, `tests/test_pipeline_sessions.py`), approved by the product owner on 24 Nov 2026: the expected default gains `--`.
- An installed config keeps its own `agent_command`. Repos installed before this fix need the `--` added by hand, which the CHANGELOG says.

## Goal

Add the TS/JS scanner from ADR 0054 to `trace_file`. It tells strings, template literals and comments apart. Tags bind from comments (to the next test) and from the title of `test(`/`it(` (to that test). Tags in any other string are ignored. Register the `ac` pytest mark in the kit. Keep `evidence.py` standard library only and its kit copy identical.
